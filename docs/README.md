# Reviewer guide

This repository contains the publication data and the code and inputs needed to
verify or independently recreate the experiment. The manuscript is maintained
separately in Overleaf.

Start with:

1. [`final_results.md`](final_results.md) — study scope, run roles, canonical
   results, hypothesis dispositions, and limitations.
2. [`../results/manifest.json`](../results/manifest.json) — checksummed inventory
   of all 27 publication runs.
3. [`../analysis/canonical/`](../analysis/canonical/) — deterministic numerical
   outputs used by the paper.
4. [`../README.md`](../README.md#verify-the-results) — verification commands and
   repository map.

Historical plans, handoff notes, working Markdown drafts, and internal review
documents are intentionally excluded. They are not required to evaluate the
paper or recreate the experiment.
