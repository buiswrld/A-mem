# docs/agent-context

Orientation for AI agents (and humans) working on this repo.

- **[PROJECT_CONTEXT.md](PROJECT_CONTEXT.md)** — start here. What the research is,
  the experimental design, repo map, vocabulary, and the invariants that keep
  experiments valid. Durable; changes rarely.
- **[STATUS.md](STATUS.md)** — concise final state and paper-only next steps.
- **[../experiment_freeze.md](../experiment_freeze.md)** — canonical data scope,
  results, hypothesis dispositions, and limitations.
- **[RELATED_WORK.md](RELATED_WORK.md)** — literature landscape, where our
  novelty actually is, threats to novelty, and the compute/fine-tuning sequencing
  that follows from it.
- **[PAPERS.md](PAPERS.md)** — per-paper quick-reference table (arXiv ID, one
  line, how to use/cite each). Look here before citing or reasoning about a paper.

The shareable narrative version of the novelty analysis lives one level up at
[`../novelty-assessment.md`](../novelty-assessment.md).
